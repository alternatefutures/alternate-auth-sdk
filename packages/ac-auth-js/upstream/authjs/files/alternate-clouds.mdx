### Environment Variables

```
AUTH_ALTERNATE_CLOUDS_ID
AUTH_ALTERNATE_CLOUDS_SECRET   # confidential clients only
AUTH_ALTERNATE_CLOUDS_ISSUER   # optional, default https://auth.alternatefutures.ai
```

### Configuration

1. Sign in to the [Alternate Clouds web app](https://clouds.alternatefutures.ai) and open **Organization › Developer**.
2. Create an app: **public** (PKCE, no secret) for browser and serverless apps, or **confidential** to get a client secret.
3. Add the **redirect URI** `http://localhost:3000/api/auth/callback/alternate-clouds` (development) and `https://{YOUR_DOMAIN}/api/auth/callback/alternate-clouds` (production).
4. Copy the client id (and the secret, shown once) into your environment variables.

<Callout>
  A public client needs only `AUTH_ALTERNATE_CLOUDS_ID`. Setting
  `AUTH_ALTERNATE_CLOUDS_SECRET` switches token requests to
  `client_secret_basic`; the issuer refuses a secret for a public client.
</Callout>

### Scopes

The default scope is `openid profile email`. Add `wallet` to receive the
user's verified wallet addresses (`did:pkh:eip155:1:<address>`) and `org` to
receive the organization picked at consent:

```ts
AlternateClouds({ authorization: { params: { scope: "openid profile email wallet org" } } })
```
